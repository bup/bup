Notable changes in 0.33.x (incomplete)
======================================

May require attention
---------------------

* `bup get` could omit intermediate items from the result when asked
  to update a ref more than once in a single invocation.  For example

      bup get -s SRC ... --pick x/SAVE-1 --pick x/SAVE-2 --pick x/SAVE-3

  would omit SAVE-2 from the updated branch, though the content would
  still be in the repository (barring a subsequent `gc`).

  To avoid this problem `bup get` now disallows multiple `METHODS` in
  an invocation, and the underlying issue will be addressed in a
  future release (i.e. 0.34.1).

General
-------

* `bup fsck` now verifies both via `git` and `par2` when only checking
  (not generating or repairing).  Previously it would only perform
  `par` verification when `par2` was available and allowed.

Bugs
----

* `bup init -r host:` now initializes the default remote repository
  (remote `BUP_DIR` or `~/.bup`).  Previously it would crash.  This
  matches the behavior of `-r` for other commands like `bup save -r`.

* `bup margin --predict` is no longer broken.  The Python code was
  incorrectly indented.
